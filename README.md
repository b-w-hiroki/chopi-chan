# 🍙 ちょぴちゃん — 子育て・妊娠 情報ノート

子育て・妊娠に関する情報を整理・精査・検索・学習・検証するための、1人用ナレッジベースです。

「妊娠中に食べて良いもの／避けた方が良いこと」「お肉を切ったまな板はそのままにせず熱湯消毒」
といった情報を、**出典と信頼度をひもづけて記録し、複数ソースで裏取り（検証）する**ことを重視しています。

**サーバー不要の静的アプリ**なので、GitHub Pages にそのまま公開してブラウザからすぐ使えます。

## 🌐 GitHub Pages で使う（おすすめ）

このリポジトリには Pages 自動デプロイのワークフロー（`.github/workflows/pages.yml`）が入っています。

**初回だけ手動の有効化が必要です**（GitHub の仕様上、Pages はリポジトリ所有者が一度
オンにする必要があり、ワークフローからは自動でオンにできません）。

1. リポジトリの **Settings → Pages** を開く。
2. **Build and deployment → Source** を **「GitHub Actions」** に変更する。
3. これで Pages が有効化されます。あとは **Actions** タブで「Deploy to GitHub Pages」を
   **Re-run**（または何かを push）すると公開されます。

一度有効化すれば、以降は push のたびに自動で再デプロイされます。

- 公開URL: `https://b-w-hiroki.github.io/chopi-chan/`

> ⚠ Pages サイト自体は公開されますが、**入力したデータはあなたのブラウザ内（localStorage）にだけ
> 保存され、サーバーには一切送信されません**。同梱のサンプル以外は他の人から見えません。

## 💻 手元（ローカル）で確認する

Node.js 18 以上があれば、確認用の静的サーバーを起動できます。

```bash
node server.js
# → http://127.0.0.1:4321 を開く
```

（`python3 -m http.server` などで `site/` を配信してもOK。`index.html` を file:// で
直接開くと初期サンプルの読み込みだけ動かない点に注意。）

## データについて

- 入力データは **ブラウザの localStorage** に保存されます（端末・ブラウザごと）。
- 初回起動時だけ、サンプルとして `site/data/entries.json` を読み込みます。
- **バックアップ・端末間の引っ越し**は、画面右上の「⬇ 書出」でJSONを保存し、別端末で「⬆ 読込」。
- `site/data/entries.json` を編集すれば、初期サンプル（新規ユーザーが最初に見る内容）を変えられます。

## 特徴

- 🗂 **整理** — カテゴリ・タグ・推奨度（推奨/注意/回避/禁止/情報）で分類。
- 🔎 **検索・絞り込み** — キーワード、カテゴリ、検証状態、推奨度。
- ✅ **検証ワークフロー** — 各情報に出典（ソース）と信頼度（高/中/低）を複数登録。
  - 単一ソースのみ／信頼度「高」が無い／異説が未整理、などを**自動で警告**。
  - 検証チェックリスト（複数ソース確認・矛盾なし・鮮度確認 等）。
  - 検証状態: 未検証 → 検証中 → 検証済 ／ 要再確認 ／ 異説あり ／ 却下。

## 画面の見方

- **要対応** … 未検証・検証中・要再確認・異説あり、または検証品質に警告がある情報の件数。
- カードの **⚠ マーク** … 出典が足りない／信頼度が低い、などの注意。
- **推奨度バッジ**（色付き）と **検証状態バッジ**（枠線）で一目で状態が分かります。

## 検証（精査）の進め方の目安

1. まず気づいた情報をどんどん追加（最初は「未検証」でOK）。
2. 出典を探して登録。できれば **公的機関・医師監修などの信頼度「高」を含めて2件以上**。
3. ソース間で食い違いがあれば「矛盾・異説のメモ」に整理し、状態を「異説あり」に。
4. チェックリストを満たしたら「検証済」に。古くなりそうなものは「要再確認」に。

## ファイル構成

```
site/                 GitHub Pages で公開される静的サイト
  index.html
  styles.css
  app.js              アプリ本体（localStorage 保存）
  data/entries.json   初期サンプルデータ
server.js             ローカル確認用の静的サーバー（任意）
.github/workflows/pages.yml  Pages 自動デプロイ
```
