# 🍙 ちょぴちゃん — 子育て・妊娠 情報ノート

子育て・妊娠に関する情報を **手元（ローカル）で** 整理・精査・検索・学習・検証するための、
1人用のナレッジベースです。

「妊娠中に食べて良いもの／避けた方が良いこと」「お肉を切ったまな板はそのままにせず熱湯消毒」
といった情報を、**出典と信頼度をひもづけて記録し、複数ソースで裏取り（検証）する**ことを重視しています。

## 特徴

- 🔒 **完全ローカル・依存ゼロ** — Node.js標準モジュールのみ。外部ライブラリのインストール不要。データはあなたのPC内（`data/entries.json`）だけに保存されます。
- 🗂 **整理** — カテゴリ・タグ・推奨度（推奨/注意/回避/禁止/情報）で分類。
- 🔎 **検索・絞り込み** — キーワード、カテゴリ、検証状態、推奨度で素早く探せます。
- ✅ **検証ワークフロー** — 各情報に出典（ソース）と信頼度（高/中/低）を複数登録。
  - 単一ソースのみ／信頼度「高」が無い／異説が未整理、などを**自動で警告**。
  - 検証チェックリスト（複数ソース確認・矛盾なし・鮮度確認 等）。
  - 検証状態: 未検証 → 検証中 → 検証済 ／ 要再確認 ／ 異説あり ／ 却下。
- 📦 **バックアップ** — JSONで書き出し／読み込み。`data/` を Git 管理すれば変更履歴も残せます。

## 使い方

必要なもの: Node.js 18 以上。

```bash
node server.js
```

起動したらブラウザで **http://127.0.0.1:4321** を開きます。

ポートを変えたい場合:

```bash
PORT=8080 node server.js
```

## データの保存場所

- すべての情報は `data/entries.json` に保存されます（1ファイル）。
- バックアップはこのファイルをコピーするだけ。
- Git でコミットすれば「いつ・何を・どう精査したか」の履歴が残ります。
- 個人データを公開リポジトリに含めたくない場合は、`data/entries.json` を `.gitignore` に追加してください
  （初期サンプルは消して構いません）。

## 画面の見方

- **要対応** … 未検証・検証中・要再確認・異説あり、または検証品質に警告がある情報の件数。
- カードの **⚠ マーク** … 出典が足りない／信頼度が低い、などの注意。
- **推奨度バッジ**（色付き）と **検証状態バッジ**（枠線）で一目で状態が分かります。

## 検証（精査）の進め方の目安

1. まず気づいた情報をどんどん追加（最初は「未検証」でOK）。
2. 出典を探して登録。できれば **公的機関・医師監修などの信頼度「高」を含めて2件以上**。
3. ソース間で食い違いがあれば「矛盾・異説のメモ」に整理し、状態を「異説あり」に。
4. チェックリストを満たしたら「検証済」に。情報が古くなりそうなものは「要再確認」に。
